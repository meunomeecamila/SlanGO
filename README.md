# 🗣️ SlanGo — Aprenda gírias com quem você ama

<p align="center">
  Um app no estilo <strong>Duolingo</strong>, mas para gírias: pais e filhos aprendem juntos as expressões da atualidade, de um jeito leve, gamificado e que aproxima gerações. 🎮👨‍👩‍👧
</p>

## 📌 Sobre o projeto

O **SlanGo** nasceu para resolver um problema real e atual: a distância geracional na comunicação. Enquanto os filhos usam gírias novas o tempo todo, os pais muitas vezes ficam por fora — e vice-versa. O app propõe um jeito divertido de reduzir essa distância, com lições curtas, quizzes, sistema de pontos e progressão por níveis, no mesmo espírito de apps de aprendizado de idiomas.
